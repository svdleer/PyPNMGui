Snapshots run in a low-traffic window (server local time, default 01:00–06:00) and continue the next night when a window ends. Each snapshot collects, per modem: full-band capture (FBC), downstream receive power and SNR/MER (SC-QAM and OFDM), upstream transmit power, the upstream channel plan and equalizer data. The package contains one CSV per measurement sorted by MAC address, and PNM files with the MAC address in the file name.
