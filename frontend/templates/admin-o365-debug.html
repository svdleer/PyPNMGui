Environment Variables:

These control O365/OIDC behavior. Set in .env.pypnm on the server:

AUTH_PROVIDER Set to o365, azure, microsoft, entra, or oidc
AZURE_AUTHORITY Tenant URL, e.g. https://login.microsoftonline.com/<tenant-id>
OIDC_CLIENT_ID App registration Client ID
OIDC_CLIENT_SECRET App registration Client Secret
DISABLE_LOCAL_AUTH Set to true to hide local login (OIDC only). Default: local + OIDC available
OIDC_ADMIN_ROLES Comma-separated group/role names/UUIDs for admin role (default: admin)
OIDC_VIEWER_ROLES Comma-separated group/role names/UUIDs for viewer role (default: viewer)
